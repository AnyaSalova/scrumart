# ScrumArt

Веб-сервис управления проектами для небольших студий видеопродакшена (Scrum и Kanban).
Лабораторная работа №2 по дисциплине «Методы и средства проектирования информационных систем»: три главные функции и страницы проекта.

Платформа: Node.js 20, фреймворк Express 4.21.2, шаблонизатор EJS 3.1.10. Данные пока хранятся в оперативной памяти контейнера.

## Запуск

```bash
docker pull annasal/mispisit-lab1:0.0.2
docker run --rm -p 8080:8080 annasal/mispisit-lab1:0.0.2
```

## Страницы

После запуска откройте http://localhost:8080

| Адрес | Что показывает |
|---|---|
| `/` | Главная: название продукта и переход к действиям |
| `/board` | Kanban-доска: задачи по стадиям и WIP-лимиты (просмотр) |
| `/cards/new` | Форма создания карточки (изменение данных) |
| `/cards/1` | Карточка одной задачи |
| `/wip-exceeded` | Отказ: попытка добавить задачу в колонку, заполненную до WIP-лимита |

Как увидеть отказ: на странице `/cards/new` выберите колонку «Монтаж» (2 из 2) и нажмите «Создать карточку».
Как увидеть ошибку данных: отправьте форму с пустым названием.

## Сборка образа (для автора)

```bash
docker buildx build --platform linux/amd64,linux/arm64 -t annasal/mispisit-lab1:0.0.2 --push .
```
