# ScrumArt

Веб-сервис управления проектами для небольших студий видеопродакшена (Scrum и Kanban).
Лабораторная работа №4 по дисциплине «Методы и средства проектирования информационных систем»: интерфейс и внешний вид рабочей версии.

Платформа: Node.js 20, фреймворк Express 4.21.2, шаблонизатор EJS 3.1.10. Данные Kanban-доски хранятся в PostgreSQL 16 — отдельный сервис `db` рядом с приложением. Драйвер базы — `pg` 8.16.3. Оформление — Bootstrap 5.3.3 и Bootstrap Icons 1.11.3, файлы библиотеки лежат в образе (ставятся из `package.json`), страницы не ходят на внешние CDN.

## Запуск

```text
Репозиторий: https://github.com/AnyaSalova/scrumart
Ветка: lab4
Pull Request: https://github.com/AnyaSalova/scrumart/pull/4
Образ: annasal/mispisit-lab1:0.0.4
Страница образа: https://hub.docker.com/r/annasal/mispisit-lab1

git clone -b lab4 https://github.com/AnyaSalova/scrumart
cd scrumart
docker compose up -d
```

После запуска откройте http://localhost:8080 — в шапке версия 0.0.4, доска пустая, таблицы приложение создаёт само.

Проверка сохранности (без флага `-v`, том `dbdata` остаётся):

```bash
docker compose down
docker compose up -d
```

## Страницы

| Адрес | Что показывает |
|---|---|
| `/` | Главная: название, версия 0.0.4, переход к действиям |
| `/board` | Kanban-доска: карточки из базы по стадиям, WIP-лимиты |
| `/cards/new` | Форма создания карточки (запись в таблицу `cards`) |
| `/cards/1` | Карточка одной задачи |
| `/wip-exceeded` | Отказ: попытка добавить задачу в колонку, заполненную до WIP-лимита |

Как увидеть отказ: создайте две карточки в колонке «Монтаж» (WIP-лимит 2), затем третью туда же.

## Хранение

| Таблица | Что хранит |
|---|---|
| `board_columns` | Стадии доски и WIP-лимиты (создаются вместе со схемой) |
| `users` | Пользователи — исполнители карточек: имя и роль (создаются вместе со схемой) |
| `cards` | Карточки задач, ссылаются на стадию и исполнителя |
| `wip_refusals` | Отказы по WIP-лимиту для страницы `/wip-exceeded` |

## Интерфейс (ЛР4)

Один интерфейс в том же приложении: продюсер и участники команды студии работают на одних и тех же экранах. Страницы рисует Express + EJS, вид собран Bootstrap 5.3.3.

| Экран | Адрес |
|---|---|
| Главная с версией и переходами | `/` |
| Kanban-доска (пустое состояние — с подсказкой и кнопкой) | `/board` |
| Форма новой карточки (ошибки ввода — в этой же форме) | `/cards/new` |
| Карточка задачи | `/cards/1` |
| Отказ по WIP-лимиту | `/wip-exceeded` |
| Не найдено | любой неизвестный адрес |
